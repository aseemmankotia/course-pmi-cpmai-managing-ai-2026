# Chapter 5 Lab: Defining Data Needs and Mapping Data Sources

**Estimated time:** 20 minutes

## Exercise

Create a data source inventory matrix for a sample use case, listing each source, owner, access permission status, format, and required refresh frequency.

## Key takeaway

Defining precise data requirements and mapping every source, owner, and access path is the foundation the CPMAI axiom 'AI projects are data projects' is built on.
