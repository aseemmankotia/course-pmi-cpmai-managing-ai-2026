## Chapter 12 Cheat Sheet — Exam Simulation & Test-Day Strategy

### Time Budget
| Metric | Value |
|---|---|
| Total questions | 120 |
| Total time | 160 minutes |
| Target pace | ~80 sec/question |
| Checkpoint interval | Every 20 questions (~26–27 min elapsed) |
| If behind pace | Flag more, guess-and-move on hard items |

### Flag-and-Return Sequence
1. Eliminate obviously wrong options
2. Select best current guess (placeholder — never leave blank)
3. Flag the question
4. Continue to next question
5. Return only with remaining time, re-read with fresh eyes

### Elimination Technique
- Discard options correct only under **different conditions** than stated
- Discard options that are **partially correct**
- Watch for **plausible distractors**: technically true statements that don't fit *this* scenario
- Answer length/order is NOT a reliable signal — ignore that myth

### Test Delivery Comparison
| Feature | Pearson VUE (Center) | OnVue (Online) |
|---|---|---|
| Location | Physical test center | Home/office |
| ID check | 2 forms, 1 govt photo ID, name match | Same ID rules + live webcam verification |
| Room control | Center-managed, secure room | Candidate must clear desk + pass 360° scan |
| Common failure point | Late arrival, ID mismatch | Visible phone/papers/second monitor/other people |

### Phase vs. Gate Question Patterns
| Pattern | Clue Language | What's Tested |
|---|---|---|
| Phase-identification | "Team is currently doing X activity" | Match activity → correct methodology phase |
| Gate-decision | "Activity done, should they proceed?" | Requires BOTH technical validation AND business/sponsor sign-off before advancing |

### Retake Policy
- Maximum **3 attempts** within a **12-month eligibility period**
- Failing attempt #1 does **not** remove eligibility for attempts #2/#3
- No requirement to fully reapply between attempts within the same window

### Top Gotchas
- Leaving a flagged question blank instead of placeholder-guessing
- Treating technical success alone as sufficient for a gate decision (business sign-off also required)
- Assuming OnVue allows a second monitor if merely powered off (must be disconnected)
- Misjudging pace early — check pace every 20 questions, not just near the end
